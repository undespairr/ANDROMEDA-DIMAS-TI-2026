# Research Outputs

Folder ini berisi hasil pengolahan dan analisis data penelitian ANDROMEDA.

## Output Files

- `dataset_audit.xlsx`: Hasil audit kualitas dan kelengkapan data.
- `dataset_cleaned.xlsx`: Dataset setelah preprocessing.
- `dataset_merged.xlsx`: Dataset hasil integrasi sumber data.
- `eda_results.xlsx`: Hasil Exploratory Data Analysis.
- `mismatch_analysis.xlsx`: Hasil analisis indeks ketidaksesuaian kesiapan digital dan capaian numerasi.
- `data_raw_extracted.xlsx`: Data hasil ekstraksi awal.
