## Pengembangan Model Identifikasi Ketidaksesuaian Kesiapan Digital Sekolah dan Capaian Numerasi untuk Pemetaan Prioritas Pendidikan di Indonesia

Repository ini berisi dokumentasi, source code, dan hasil analisis penelitian Tim ANDROMEDA dalam kompetisi DIMAS-TI AMLI 2026 bidang Penambangan Data.

## Research Overview

Penelitian ini bertujuan mengidentifikasi ketidaksesuaian antara kesiapan digital sekolah dan capaian numerasi untuk mendukung pemetaan prioritas pendidikan di Indonesia.

## Methodology

- Data preprocessing dan integration
- Exploratory Data Analysis (EDA)
- Standardization
- Mismatch Index Analysis
- Quadrant Mapping
- Bootstrap Analysis
- Sensitivity Analysis
- Kruskal-Wallis Test
